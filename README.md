# Muse iPhone 用量小组件

解锁手机就能看 Muse 用量，不用打开 App 查。

## 显示什么

- **周额度剩余**：进度条 + 百分比，重置倒计时
- **额外 Token 剩余**：进度条 + 百分比，还剩多少（例如 5.5B）
- 颜色：剩余 ≥25% 绿色，<25% 黄色，<10% 红色（两条都按这个规则）
- 取不到数据时显示缓存，并标“缓存”；连缓存都没有才显示离线

为什么两条都显示：周额度经常是 0%，但额外 Token 还有很多，那时其实还能用。只看周额度会一直红，没意义。

## 数据怎么来

- VM 上每 3 小时跑 `subscription-status status`，解析成 `muse-usage.json`，推到这个公开仓
- 小组件直接读公开的 JSON，不用令牌，不碰 Muse 登录
- 数字本身不敏感，只有用量百分比和剩多少 Token，没有账号信息
- 刷新时间是 iOS 定的，3 小时是服务端更新频率，不是小组件保证刷新

## 安装步骤（iPhone）

1. App Store 免费安装 Scriptable
2. 打开 Scriptable → 右上角 `+` → 粘贴本仓 `MuseUsage.js` 的全部内容 → 命名为 `MuseUsage`，保存
3. 长按桌面空白处 → 左上角 `+` → 搜 Scriptable → 选尺寸（建议中号）
4. 点添加好的小组件 → Edit Widget → Script 选 `MuseUsage`
5. 回到桌面，等 iOS 刷新一次就会出数。想立刻看：在 Scriptable 里打开这个脚本点运行

## 文件

- `muse-usage.json`：最新用量数据（每 3 小时更新）
- `MuseUsage.js`：小组件脚本
- `update_usage.py`：VM 上的更新脚本（`subscription-status` → 解析 → 推仓）

## 排障

- 显示离线：没网且手机里没缓存过，先联网打开脚本跑一次
- 数字几个小时不变：正常，服务端 3 小时才更新一次，iOS 也不会每分钟刷新小组件
- 之前试过只读令牌那条路：细粒度令牌走 GitHub API 一直 401，令牌本身不被认，已放弃，改公开取数，不再需要令牌
